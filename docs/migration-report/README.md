## Scope Boundaries

| Boundary | Status | Statement |
|---|---|---|
| datasourceType inference | `OUT_OF_SCOPE` | The converter does not infer datasourceType from XML; same-name FDL connections or product adapters own it. |
| FDL connection creation | `OUT_OF_SCOPE` | Users create FDL data connections whose names match XML `CONNECTIONNAME` values. |
| credential/secret migration | `OUT_OF_SCOPE` | Passwords, tokens, cookies, licenses, and secrets are not copied, printed, inferred, or stored. |
| schedule migration | `OUT_OF_SCOPE` | Informatica schedules are outside this migration phase. |
